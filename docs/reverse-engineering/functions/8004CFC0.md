# 0x8004CFC0

**Release:** Europe PAL — SCES-01753  
**Status:** Under investigation  
**Confidence in prerecorded-FMV association:** High

## Summary

`0x8004CFC0` is a function in the PAL SCES-01753 executable that is
strongly associated with prerecorded FMV playback.

Runtime testing under GDB shows that the function executes extremely
frequently while prerecorded story movies are playing. It was not
observed executing continuously during the title/menu or during the
Chief Puddle stage demo.

The exact role of the function is not yet known. Do not currently treat
it as equivalent to `PlayFMV`, `DecodeFrame`, or any other specific
semantic function.

## Runtime observations

### Prerecorded story FMV: Jet Baby

A breakpoint on `func_8004CFC0` was hit almost immediately during
Jet Baby playback.

Repeated `continue` commands caused the breakpoint to fire very
frequently throughout playback.

An automatic breakpoint command confirmed repeated entries:

    #0 func_8004CFC0()
    #1 psx_dispatch_game_compiled()
    #2 dirty_ram_dispatch()

### Title/menu

After leaving the initial FMV path, the breakpoint did not continue
firing through ordinary title/menu execution.

### Stage 2 / Chief Puddle demo

The entire Chief Puddle demo sequence completed without the breakpoint
being hit.

This is an important negative control: a noninteractive scripted
sequence is not sufficient by itself to cause `0x8004CFC0` to execute.

### Later prerecorded story FMV

The breakpoint began firing again while transitioning into the next
prerecorded story movie.

During actual movie playback, it again executed extremely frequently.

## Initial static observations

The function begins by:

- creating a 40-byte stack frame;
- preserving several registers;
- reading several halfwords from the structure referenced by the
  original `$a0`;
- copying some of those values into another structure;
- performing arithmetic involving two halfword values;
- allocating additional stack space based on the calculated result;
- eventually transferring control to `0x8004D24C`.

These observations alone are not sufficient to assign a semantic name
to the function.

## Rejected or weakened hypotheses

### General game/main loop

**Rejected.**

The function can remain unexecuted for extended periods while the game
continues normally through menus and stage-engine activity.

### Generic cutscene/demo handler

**Rejected.**

The Chief Puddle demo completed without triggering the breakpoint.

### `PlayFMV`

**Unproven.**

The function is strongly correlated with prerecorded FMV playback, but
we do not yet know whether it controls playback, processes video data,
handles streaming, performs synchronization, or implements some lower-
level operation used by the movie subsystem.

### `DecodeFMVFrame`

**Unproven.**

No direct evidence yet establishes MDEC decoding as this function's
specific responsibility.

## Current hypothesis

`0x8004CFC0` belongs to, or is heavily used by, the prerecorded FMV
playback path.

Possible roles include:

- movie playback processing;
- video-data transformation;
- stream-buffer processing;
- frame preparation;
- synchronization;
- an FMV-specific inner routine.

These possibilities are hypotheses only.
