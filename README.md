# Um Jammer Lammy: Encore!

**Um Jammer Lammy: Encore!** is an independent preservation,
reverse-engineering, and modernization project for *Um Jammer Lammy*.

## Goals

Encore aims to preserve the original game while building a modern,
portable implementation with improved platform support, rendering,
input, timing, accessibility, archival features, and modding capabilities.

The original experience should always remain available.

## Reference Version

Initial reverse-engineering work targets:

- Um Jammer Lammy
- Europe / PAL
- Disc ID: SCES-01753

Additional regional versions may be documented and supported later.

## Bring Your Own Game

Encore does not distribute the original game, PlayStation BIOS files,
or other copyrighted retail assets.

Users will provide their own legally obtained game data. Encore's
import tools will identify supported releases and prepare the required
local data.

## Project Status

Very early development.

Current goals:

1. Establish project infrastructure.
2. Build a reproducible original-disc identification/import pipeline.
3. Document the PAL SCES-01753 executable and data layout.
4. Reverse-engineer individual game systems.
5. Gradually replace PlayStation-specific dependencies with portable,
   native implementations.
